# 双声桌面版

桌面版提供原生编辑窗口，支持 Windows、macOS 和 Linux。窗口以文本编辑为主，设置、个人词库和本地助手在独立对话框中打开。支持拼音 / 小鹤双拼 / 粤拼候选及普通话 / 粤语 / 英语 / 自动检测本地听写。默认在窗口中审阅后复制或保存；Windows/macOS 可明确启用“自动插入原目标”，支持范围见下文。系统拼音输入通过发行包内的 Rime 配置安装。

## 使用发行包

从 GitHub Releases 下载对应系统和处理器架构的压缩包，完整解压后运行 `Shuangsheng`（Windows 为 `Shuangsheng.exe`，macOS 为 `Shuangsheng.app`）。不要单独移动可执行文件，必须保留旁边的依赖和数据目录。

拼音输入开箱可用：输入 `nihao`，按空格选择首个候选，按 `1–9` 选择对应候选，或双击候选。向下键进入候选列表，空格选词；**回车提交输入框原文**，`Escape` 清除组合并取消录音。粤拼数字是声调：输入 `nei5` 时保留 `5`，用 `Alt+数字` 选择候选。原生 Fcitx5 和浏览器入口也保留粤拼声调。切换“简体 / 繁體”影响之后的候选和语音，不改写已有文本。“中 / EN”切换中文候选和英文原文模式。

要在其他应用中直接使用系统拼音输入，先安装对应平台的 Rime 前端（Windows 小狼毫 Weasel / macOS 鼠须管 Squirrel / Linux Fcitx5-Rime），然后在设置中选择全拼、双拼或粤拼，点击“安装系统输入方案…”。确认框明确说明将安装当前选择的方案及共享拼音依赖；程序会备份将被替换的已有文件。最后在输入法菜单中“重新部署”，按 `` Ctrl+` `` 或 `F4` 选择“双声拼音”、“双声小鹤双拼”或“双声粤拼”。此按钮安装输入方案，不替你安装系统输入法前端；自定义目录可使用发行程序的 `--install-rime --user-dir 路径` 命令；源码安装脚本支持 `--schemes pinyin shuangpin jyutping` 明确安装全部三种方案。

语音需要首次准备模型。在“设置…”中点击“下载…”，确认后下载 `large-v3`；此步骤需要联网、数 GB 的下载空间，完成后可离线听写。不会在启动或录音时自动下载。也可以在设置中点击“选择模型…”，选择已下载、包含 `model.bin`、`config.json` 和 `tokenizer.json` 的 faster-whisper/CTranslate2 模型目录；手动选择会保存到本机偏好，之后仍使用该目录。粤语建议使用 `large-v3`，其他模型可能不支持粤语。

也可以通过命令行准备模型：

```powershell
# Windows，位于解压后的程序目录
.\Shuangsheng.exe --download-model --model large-v3
```

```bash
# macOS，位于解压后的程序目录
./Shuangsheng.app/Contents/MacOS/Shuangsheng --download-model --model large-v3
# Linux，位于解压后的程序目录
./Shuangsheng --download-model --model large-v3
```

首次加载大模型和 CPU 识别可能较慢，需要足够内存。设置中的“预热”提前加载已缓存模型，“卸载”释放已加载模型；状态显示后端、模型、计算设备和是否就绪。下载、加载失败会保留编辑文本。SenseVoice 是可选后端，需要自行准备本地模型目录；它不支持 Whisper 的专有词和背景提示。默认仍为 Whisper large-v3 / CPU，CUDA / 自动设备可在设置中选择；软件不会在启动或录音时自动下载模型。

## 录音与权限

1. 在“设置…”中选择普通话、粤语、英语或自动检测，并选择输出简繁。
2. 首次使用时允许系统麦克风权限。默认使用系统默认麦克风；在设置中点击“刷新麦克风”可指定其他设备。
3. 点击“开始录音”，说话后点击“停止并识别”。录音中会显示实际输入电平和本地识别预览，预览尾句可能修订；停止后完成最后一句再提交。单次录音最长 115 秒。可改为“按住说话”，按住按钮 / 全局组合键录音，松开结束。
4. 检查并修改识别文字，点击“复制全部”，切换到目标应用，用系统粘贴快捷键粘贴。

可用时，默认全局 `Ctrl+Alt+Space` 开始/停止录音；组合键可在设置中修改。macOS 对应 `Control+Option+Space`。快捷键不会切换当前应用的焦点。macOS 可能需要在“系统设置 → 隐私与安全性”中授权“辅助功能”及“输入监控”，变更后重启应用。未授权仍可使用窗口按钮。Linux Wayland 下默认禁用全局键盘监听，使用窗口按钮；X11 下取决于桌面权限。限制依据 [pynput 官方平台说明](https://pynput.readthedocs.io/en/latest/limitations.html)。

“取消”或窗口内 `Escape` 丢弃当前录音/结果。若模型正在识别，原生推理需结束后才能再次录音；等待期间不会插入取消的结果。关闭窗口会提示尚未保存的文本；选择取消保留窗口，选择保存后关闭，选择“否”放弃文本并删除恢复草稿。录音只在内存中处理，不写音频文件。模型后台推理结束前取消的结果不会提交。

剪贴板繁忙时，文字仍保留在文本区，可以重试复制或“保存文本…”。Linux 的剪贴板可能需要本窗口持续运行，请在关闭窗口前完成粘贴。默认不保存编辑草稿。设置中可明确启用本地草稿恢复；此时文本以 UTF-8 保存在偏好目录的 `desktop-draft.txt`，启动时询问是否恢复。关闭草稿选项会删除该恢复文件。“清空（可撤销）”和“撤销”可恢复误清除的文本。

## 偏好、个人词库和本地助手

语言、文字、语音模型、计算设备、麦克风、组合键、按住说话、输入方案、模糊音对、候选数量、字号、主题、紧凑窗口和界面语言保存在本机 JSON。主题支持浅色、深色、高对比度和系统默认；主要界面可切换中文 / English。设置对话框可滚动，较小屏幕也能访问所有选项。

“词库…”管理与浏览器共享的个人词库：添加 / 编辑 / 删除、置顶、拼音 / 粤拼、快捷短语以及 JSON 导入 / 导出。文本模板可包含换行和制表符。选择候选会学习明确提交的词，选词后展示后续预测；用于候选的完整编辑上下文只在当前查询中使用。保存到学习记录的上下文限于此前明确提交的组合输入，不把任意编辑草稿保存为学习上下文。

“应用配置…”可为 Windows 可执行文件完整路径或 macOS bundle ID 设置语言、简繁和输入方案。最近一次录音捕获的目标标识会预填。配置只覆盖这三项；不会通过应用配置打开自动插入。

“本地助手…”提供润色、翻译和续写预览，默认关闭。启用后，仅在点击“生成预览”时，将当前文本发送到设置的本机 HTTP 模型服务，不逐键调用。预览可编辑，再明确选择替换或插入；原文变化时禁止用旧预览替换，应用后可以撤销。助手地址只允许回环地址，模型名称留空可从本机服务读取。没有可用本机模型时保留原文并报告错误。

设置目录通常为 Linux `$XDG_CONFIG_HOME/shuangsheng`（默认 `~/.config/shuangsheng`）、Windows `%APPDATA%/shuangsheng` 或 macOS `~/Library/Application Support/shuangsheng`。测试 / 独立配置可用 `IME_SETTINGS_PATH` 和 `IME_LEXICON_PATH` 指定文件。浏览器的恢复草稿单独保存在当前浏览器的 localStorage，也需要明确启用。

## 原目标插入与录音浮窗

自动插入默认关闭。打开后，通过全局快捷键开始录音时捕获原目标，完成时再次验证原应用、原编辑控件和当前焦点；不切换到另一个应用，也不恢复已经改变的焦点。结果始终保留在双声编辑区。

- **Windows**：仅支持已识别的原生 Edit / RichEdit 控件。密码、只读、不可见、禁用或未知控件返回审阅 / 复制；使用 Unicode 剪贴板和针对原控件的 `WM_PASTE`，不向全局键盘注入 Ctrl+V。网页、游戏和自绘编辑器可能不在支持范围。
- **macOS**：需要已有的辅助功能授权和 PyObjC，验证 AX 聚焦应用 / 编辑元素；安全输入框、未知或不可编辑元素返回审阅 / 复制。采用本机剪贴板和发送到捕获进程的 Cmd+V。粘贴前多次检查焦点；操作系统没有原子“验证元素并粘贴”事务，因此仍需要在实际目标应用验收。
- **Linux / Wayland**：不通过桌面伴侣注入原始按键。使用编辑 / 复制，或项目的 Fcitx5 系统输入入口。

设置中的录音浮窗为明确启用项，在 Windows 使用 NOACTIVATE 窗口，在 macOS 使用非激活 NSPanel，显示阶段、电平和转写预览，不接收键盘焦点。Linux 保留主窗口的电平与预览，因为 Tk 无法对所有 Wayland 合成器承诺不抢焦点。浮窗不可用时录音流程仍可运行。

## 应用内更新

工具栏中的“检查更新…”打开关于 / 更新窗口，显示当前版本和本机更新支持情况。程序不在启动时联网检查；点击“检查更新”才查询 GitHub 最新稳定发行版。发现更新后，先点击“下载更新”，窗口显示下载进度，后台完成 SHA256 校验、安全解压和新程序试运行。下载完成后不会自动安装；带版本号的“安装并重启”按钮需要再次确认。

安装前须结束录音或模型操作，并提交或取消输入框中的组合。正文有未保存修改时必须选择保存位置；取消保存或保存失败都会中止安装。安装和等待新窗口就绪期间保持原窗口，暂停编辑；只有新版本成功启动并确认窗口就绪后才关闭原窗口。失败会显示原因、恢复编辑，并继续使用原版本。检查或下载时可关闭更新窗口，之后返回的结果不会被采用；下载在下一次进度回调时中止。安装期间需等待结果，不能提前关闭窗口。

Windows、macOS 和 Linux 的发行包安装到用户目录中的独立版本目录，保留旧版本。支持的平台上，从源码打开的桌面窗口也可下载并启动对应发行包。Linux 若已安装项目的本机 Fcitx5 插件，更新还会更新该插件并短暂重启输入法，确认框会提示可能的输入中断；没有插件时不自动安装。Rime 前端和模型权重不属于应用更新。

**v0.3.0 旧发行包没有应用内更新入口**。需先从 GitHub Releases 手动下载包含更新入口的新版本，之后才能使用上述流程。

## 从源码运行

推荐使用 Python 3.12（或 3.11）：

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
python -m pip install -r requirements-desktop.txt
python -m ime.desktop
```

Linux 还需要 Tk 和 PortAudio，例如 Ubuntu/Debian：

```bash
sudo apt-get install python3-tk libportaudio2
```

`sounddevice` 在 Windows/macOS 的 pip 安装通常自带 PortAudio；其他平台参见 [sounddevice 安装文档](https://python-sounddevice.readthedocs.io/en/latest/installation.html)。从源码运行时，系统麦克风权限可能显示为 Python 或终端程序。

macOS 安装桌面依赖时会自动安装 PyObjC 的 ApplicationServices、Cocoa 与 Quartz 框架绑定；发行包包含这些依赖。程序通过 `HIServices.AXIsProcessTrusted()` 查询已有的辅助功能授权，不自动弹出授权请求。该绑定属于 [pyobjc-framework-ApplicationServices](https://pyobjc.readthedocs.io/en/latest/apinotes/HIServices.html)。

```bash
# 从源码显式下载模型
python -m ime.model_setup --model large-v3
# 禁用可选的全局快捷键监听
python -m ime.desktop --no-hotkey
# 检查发行包资源，无需屏幕、麦克风或网络
python -m ime.desktop --smoke-test
# 打开窗口检查拼音、剪贴板和按钮状态，然后自动退出
python -m ime.desktop --gui-smoke-test
```

支持 `IME_WHISPER_MODEL`（模型名称或本地目录）、`IME_WHISPER_DEVICE`（默认 `cpu`，兼容 CUDA 的环境可自行选择 `cuda`）和 `HF_HOME`。默认使用本机 CPU 的 int8 推理。软件包不包含模型权重，缓存位置由共享语音模块统一管理。

## 常见问题

- **无法录音**：在系统声音设置中确认输入设备可用、未静音并已授权麦克风；更换设备后点击“刷新设备”。程序采用设备默认采样率，最高 48 kHz，并在识别前转为模型需要的音频格式。
- **无法加载模型**：先通过下载按钮准备模型，或选择完整的 faster-whisper 本地模型目录。模型损坏、缺失文件或显存不足也会产生明确错误。选择 CUDA 失败时恢复默认 CPU。
- **录音太短/静音**：至少录制 0.2 秒并确认输入电平；此类录音会直接拒绝，不启动模型识别。
- **录音中断/丢帧**：关闭抢占音频设备的程序，更换设备再试，避免对不完整音频给出误导结果。
- **无法打开窗口**：源码运行需要可用的 Tk 和图形桌面会话；SSH/无显示环境只能运行 `--smoke-test`，或使用项目的浏览器版。

## 开发验证

```bash
python -m unittest tests.test_desktop_voice tests.test_desktop tests.test_insertion tests.test_desktop_overlay -v
# Linux 无物理显示时运行实际 Tk 窗口测试
xvfb-run -a python -m unittest tests.test_desktop -v
```

硬件无关测试验证音频边界、采样率、静音、权限错误、取消、并发保护及结果传递。窗口测试还验证实际 Tk 设置 / 词库 / 应用配置 / 助手对话框、语言切换、偏好持久化、可撤销清空、实时预览与电平、取消结果丢弃。平台适配器的焦点变化、敏感 / 未知控件、剪贴板所有权和浮窗不激活标志通过模拟测试验证。Linux 图形会话下已运行实际 Tk 9 窗口测试，Chromium 浏览器测试通过假麦克风验证增量 PCM、相同序号重试、取消及避免重复提交。

更新窗口通过注入更新器测试真实 Tk 控件，并用模拟下载 / 安装验证进度、异步响应、关闭后丢弃结果、保存取消、安装确认和失败恢复；这些 UI 测试不联网，也不重启应用。Windows/macOS 的实际应用更新仍需在对应系统验收。

尚未完成真实 Windows/macOS 插入 / 浮窗、系统麦克风授权、语音准确率或实际 GPU 性能验收；这些不能由跨平台模拟测试替代。
